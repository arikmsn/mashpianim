## מדידה

**Google Search Console** (חינם, צריך חשבון גוגל של העסק):
1. נכנסים ל-https://search.google.com/search-console ומוסיפים נכס מסוג "דומיין": `mashpian.online`.
2. גוגל נותן רשומת TXT. מוסיפים אותה ב-GoDaddy: DNS → Add record → TXT, Host `@`, הערך שגוגל נתן. אחרי כמה דקות לוחצים "אימות".
3. ב-Sitemaps שולחים: `https://www.mashpian.online/sitemap.xml`.

**Bing Webmaster Tools:** https://www.bing.com/webmasters, "Import from Google Search Console" מייבא את הנכס וה-sitemap בלחיצה אחת (אחרי שלב 1).

**אנליטיקס:** הבחירה של הבעלים. Vercel Web Analytics הוא הפשוט ביותר (מופעל בדשבורד של Vercel, דורש שורת קוד אחת שנוסיף כשתבחרו), או GA4 (חינם, יותר נתונים, דורש באנר עוגיות לפי הפרטיות). עד אז, קישורי ה-utm נראים כבר עכשיו בלוגים של Vercel.
